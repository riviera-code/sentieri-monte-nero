Collega GitHub per caricare le note

Serve una volta sola su ogni telefono. La chiave resta salvata solo su questo dispositivo.

  1. Apri GitHub → Nuova chiave (fine-grained).
  2. Nome: Sopralluoghi Monte Nero. Scadenza: quella che preferisci.
  3. Repository access → Only select repositories → sentieri-monte-nero.
  4. Permissions → Contents → Read and write. Nient'altro.
  5. Genera la chiave, copiala e incollala qui sotto.
